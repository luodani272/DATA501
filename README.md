### BFRdist
This is a package that encompasses the BFR Distribution.

### Instructions for loading the Repository:

1. Git Checkout this repository
2. Use getwd() and setwd() to get into the right folder
3. Run the following commands in your R terminal
```R
install.packages("BFRdist")
install.packages("devtools")

Rcpp::compileAttributes()
devtools::load_all()
```
